Aurora Pay Bobathon test raporu

Test tarihi: 18 Kasım 2026. Ortam: macOS, Python 3.14, Bob Shell 2.0.6, Bob IDE 2.3.0.

Özet

Laboratuvar, GitHub şablonunun 10 Kasım commit’iyle temiz bir klonda test edildi. Ortam ./setup.sh --scanners ile kuruldu. Kurulum yaklaşık 25 saniye sürdü.

Görevler katılımcı kartlarına göre yürütüldü. Shell turunda bob run için tur ve maliyet sınırları uygulandı. Görev sonuçları ./verify/run.sh mN ile kontrol edildi.

İlk Shell turunda M0 ile M7 doğrulamaları geçti. Ardından M1, M3, M5 ve M6 Bob IDE’de elle denendi. Ayrı bir özel GitHub reposunda PR açıldı, iki CI kontrolü geçti ve M8 doğrulaması 6/6 tamamlandı. Katılımcı şablonundaki düzeltmeler fix/dryrun-bulgulari dalında. Katılımcı şablonunun main dalı açık test reposuna başarıyla gönderildi.
