Aurora Pay Bobathon test raporu

Test tarihi: 18 Kasım 2026. Ortam: macOS, Python 3.14, Bob Shell 2.0.6, Bob IDE.

Özet

Laboratuvarı uçtan uca Bob ile test ettim. Repo GitHub template'inden (10 Kasım commit'i) temiz klonlandı ve ./setup.sh --scanners ile kuruldu. Kurulum yaklaşık 25 saniye sürdü.

Görevleri Bob'a katılımcı gibi, görev kartındaki tarife göre yaptırdım. Bob Shell işleri bob run ile tur ve maliyet sınırı koyarak çalıştırdım. Her adımdan sonra ./verify/run.sh mN ile kontrol ettim.

Sonuç olumlu. M0 ile M7 doğrulamaları geçti. M8 3/6 kaldı, çünkü push ve PR bilinçli olarak yapılmadı. Bulunan sorunlar Bob'a düzelttirildi ve fix/dryrun-bulgulari dalında duruyor. Dört IDE anı uzaktan sürülemedi, bunlar aşağıda önerilerde.

Kalan öneriler

  • Bob IDE'de M1, M3 (Settings), M5 (Findings paneli) ve M6 (onay penceresi) bu testte uzaktan sürülemedi. Bunlar Bob Shell ile aynı modlarla yapıldı. Bu dört anı etkinlikten önce IDE'de bir kez elle denemek gerekir.
  • M8 push ve PR bu testte yapılmadı. Katılımcının kendi kopyasında GitHub push protection, template'teki sahte gizli bilgilere takılır mı, ilk push'ta görülmeli.
  • Tek seferde iyi bir prompt M2'yi, M4'ü ve M5'in bir kısmını birlikte çözebiliyor. Görev kartlarındaki kapsam notları bunu azaltır. Facilitator yine de takip etmeli.
  • 3 saatlik programda kesilecek ilk görev M4 olabilir. Bob M2'de kapsamı aşarsa M4 zaten boş kalıyor.
